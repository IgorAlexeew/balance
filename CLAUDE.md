# Инструкции для Claude Code

- Порядок работы с ветками и PR — [`docs/WORKFLOW.md`](docs/WORKFLOW.md). Обязателен: ветка от `develop`,
  небольшие самостоятельные PR с шагами функциональной проверки, слияние только после «ок» владельца.
- Тесты обязательны в каждом PR и **не подгоняются под код**: пишутся от ожидаемого поведения через публичный
  интерфейс (HTTP, экран глазами пользователя). Правила — раздел «Тесты» в `docs/WORKFLOW.md`.
- Текущие планы — в [`docs/`](docs/). Перед работой над пунктом плана сверяйтесь с ним и отмечайте выполненное.
- Запуск и команды — в [`README.md`](README.md). Перед PR: `pnpm format:check && pnpm check`.
- Общение, описания PR и коммиты — на русском.
